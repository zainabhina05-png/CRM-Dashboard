## Seeding Instructions

```bash
# 1. Copy and configure environment
cp server/.env.example server/.env
# Edit: set MONGO_URI, JWT_SECRET, JWT_REFRESH_SECRET

# 2. Install dependencies
cd server && npm install

# 3. Run seed (from project root)
cd ..
npm run seed
# → Creates 3 users, 85 leads, 35 reminders
# → Writes DEMO_CREDENTIALS.md with last-generated timestamp

# 4. Reset and re-seed (wipes all data first)
npm run seed:reset && npm run seed
```

### Production Safety
The seed script refuses to run unless:
- `NODE_ENV` is `development` or `test`, **OR**
- `ALLOW_SEED=true` is explicitly set, **AND**
- Database name contains `demo` or `dev`

---

## Security Notes

- Demo credentials are intentionally simple — **never use in production**
- All passwords are bcrypt-hashed (salt rounds = 12) even in demo mode
- JWT secrets in demo are separate from production; regenerate with `npm run generate-secrets`
- Demo data can be wiped cleanly with `npm run seed:reset`
